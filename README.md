# FlowMetrix

### MT5 Multi-Account Manager & Copy Trading Software

**FlowMetrix** is a Windows software designed to help traders manage multiple **MetaTrader 5 (MT5) accounts and terminals from a single dashboard**.

Instead of repeatedly switching between separate MT5 terminals, FlowMetrix provides a centralized workspace for managing and monitoring multiple accounts.

## 🔄 MT5 Copy Trading

FlowMetrix supports workflows where trades can be copied between multiple MT5 accounts.

This makes it useful for traders who need to execute or manage similar trading activity across multiple accounts instead of handling every terminal separately.

---

## 🖥️ Multiple MT5 Terminals

Running several MT5 terminals can make account management difficult because each terminal operates independently.

FlowMetrix provides a centralized interface designed to make working with multiple terminals more convenient.
